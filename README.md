# T01 - Introducción al desarrollo con hilos y procesos

Proyecto realizado en C# para aprender los conceptos básicos de programación concurrente.

Incluye tres ejercicios sobre creación de hilos (`Thread`), condiciones de carrera y sincronización de datos (`lock` e `Interlocked`), y ejecución de tareas (`Task` y `Task.WhenAll`).

También se comparan diferentes métodos de ejecución y sus tiempos mediante `Stopwatch`.

**Tecnologías:** C#, .NET 10 y Visual Studio.
